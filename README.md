# Лабораторная работа 4

Учебный репозиторий для проверки команд Git: status, add, commit, branch, checkout, merge, log, show, diff, restore, revert, push, clone и pull.

Автор: Маматисаков Элмурат Сапарбекович. Для обмена используется отдельный локальный bare-репозиторий git_remote.git. Токены и пароли не хранятся в файлах.

## Роли при совместной работе

- Владелец (Admin): управляет репозиторием и доступом.
- Разработчик (Write): работает в отдельных ветках и предлагает изменения.
- Проверяющий (Read): просматривает код и историю без права записи.

Роли описаны как схема для команды. Облачные права доступа не назначались: доступный токен GitHub разрешает чтение профиля, но создание репозитория возвращает HTTP 403.
