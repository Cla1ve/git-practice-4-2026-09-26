# Лабораторная работа 4

Учебный репозиторий для проверки команд Git: status, add, commit, branch, checkout, merge, log, show, diff, restore, revert, push, clone и pull.

Автор: Маматисаков Элмурат Сапарбекович. Локальный bare-репозиторий git_remote.git используется для проверки push, clone и pull. Публичная копия работы: https://github.com/Cla1ve/git-practice-4-2026-09-26. Токены и пароли не хранятся в файлах.

## Роли при совместной работе

- Владелец (Admin): управляет репозиторием и доступом.
- Разработчик (Write): работает в отдельных ветках и предлагает изменения.
- Проверяющий (Read): просматривает код и историю без права записи.

В опубликованной копии для коммитов использован адрес GitHub noreply, чтобы не показывать личную почту. Поэтому идентификаторы коммитов в локальной и публичной историях отличаются.
