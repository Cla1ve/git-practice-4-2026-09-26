# Лабораторная работа 4

Учебный репозиторий для проверки команд Git: status, add, commit, branch, checkout, merge, log, show, diff, restore, revert, push, clone и pull.

Владелец: Cla1ve. Репозиторий закрытый. Токены и пароли не хранятся в файлах.

## Роли при совместной работе

- Владелец (Admin): управляет репозиторием и доступом.
- Разработчик (Write): работает в отдельных ветках и предлагает изменения.
- Проверяющий (Read): просматривает код и историю без права записи.

В этой индивидуальной работе фактически назначен только владелец. Остальные роли описаны как схема для команды; приглашения другим людям не отправлялись.
